# MonoIcon 2.1.0

**versionCode 3** · 上一个版本 / Previous release: 2.0.1

## 中文

本次为功能更新，重点适配 HyperOS 4 测试环境，并完善主题图标的显示与设置体验。

- 适配 HyperOS 4 测试环境的系统桌面，桌面、文件夹预览和最近任务均使用统一的单色主题图标。
- 修复部分图标不变色、变成纯色块或仍显示原图的问题。
- 完善电话、日历、时钟和小爱等系统应用的主题图标。
- 改善圆形图标的尺寸，支持与系统默认形状切换。
- 配色方案、Lawnicons 和总开关的切换更可靠，关闭后正确恢复原图标。
- 壁纸或系统设置变化后，图标样式会自动跟上，无需手动干预。
- 安装或更新模块后，设置能更顺畅地重新生效。

**兼容性说明：本版本仅适配并验证了当前测试环境（系统桌面 RELEASE-8.01.02.6144-260818-08251107-R），其他桌面版本未经测试，不保证可用。系统或桌面更新后请重新确认。**

使用提示：需要为 MonoIcon 授予 root 权限，并在 LSPosed 中启用「系统桌面」和「系统界面」作用域；更新模块后请重启作用域。启用主题图标时，日历、时钟使用静态图案。

## English

This feature release focuses on adapting to the HyperOS 4 test environment and polishing themed icon rendering and settings.

- Supports the HyperOS 4 test launcher: the home screen, folder previews and Recents now use consistent monochrome themed icons.
- Fixes icons that refused to change colour, turned into solid blocks or stayed as the original artwork.
- Improves themed icons for system apps such as Phone, Calendar, Clock and the assistant.
- Improves circular icon sizing and switching back to the system default shape.
- Colour schemes, Lawnicons and the master toggle now apply and revert more reliably.
- Icon style follows wallpaper and system setting changes automatically.
- Settings take effect more smoothly after installing or updating the module.

**Compatibility: this version is adapted and verified only for the current test environment (launcher RELEASE-8.01.02.6144-260818-08251107-R). Other launcher versions are untested and not guaranteed to work. Re-check after system or launcher updates.**

Usage: grant MonoIcon root access and enable both the Launcher and System UI scopes in LSPosed; restart the scopes after updating. Calendar and Clock use static artwork while themed icons are enabled.
