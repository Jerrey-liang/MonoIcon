# HyperOS 4 使用与兼容性

<a id="compatibility"></a>

## 适配范围

MonoIcon 通过 Root 同步 HyperOS 的系统主题图标。主题同步适用于 Android 主用户（用户 0），显示效果取决于设备的主题支持。

<a id="device"></a>

## 启用与检查

1. 在 LSPosed 启用 MonoIcon，勾选「系统界面」和「系统框架」。打开 MonoIcon，按 Root 管理器提示授权。「启用模块」默认开启。
2. 首次启用「系统框架」作用域后，重启手机使它生效。如需重启桌面和系统界面，使用右上角电源菜单的「重启桌面和系统界面」。更换配色、壁纸或图标样式后，MonoIcon 会自动同步主题图标。
3. 在「运行诊断」查看「系统主题图标」的同步状态。

从使用 NativeHook 的版本升级后，请重启一次手机，退出桌面进程中已加载的旧模块。

「系统框架」作用域用于监测主题变化和图标归档的 DRM 校验。检测到系统拒绝并移除归档后，MonoIcon 会暂停同步，并在归档位置仍为空时恢复有效备份。若已经换上其他主题，MonoIcon 会保留当前主题。也可在「运行诊断」检查变动并恢复备份。

<a id="large-icons"></a>

## 大图标

MonoIcon 为桌面正在使用的单应用静态大图标换色，支持 2×1、1×2 和 2×2。先在桌面选用当前系统主题提供的大图标，再在 MonoIcon 的「图标样式」或「应用图标定制」调整外观。圆形设置下，横向和纵向大图标呈胶囊形。

动态大图标和应用配对图标保留主题原样。更改主题或大图标后，可在「运行诊断」查看同步状态。若桌面仍显示旧样式，可重启桌面。

在 Redmi K50（HyperOS 4.0.5.0、桌面 7755）上，「主题」把已选大图标登记在 `/data/system/theme/large_icons/0/apps/desktop/runtime_largeicon.config`。同目录下的 `<包名>/<尺寸>/res/drawable-<密度>/<包名>.png` 是桌面读取的图片。已在桌面验证 QQ 的 2×2 图标，关闭模块后，三个尺寸的九张 PNG 均恢复为原文件内容。

<a id="troubleshooting"></a>

## 排查与恢复

| 现象 | 处理方法 |
| --- | --- |
| 图标未变化 | 检查 Root 授权、LSPosed 作用域和「启用模块」，再通过「刷新运行信息」检查「系统主题图标」的状态。 |
| 更换系统主题后停止同步 | 确认「启用模块」已打开，在「运行诊断」选择「在当前主题上应用 MonoIcon」。之后关闭模块时会恢复到这个主题。 |
| 系统移除了图标主题，应用仍有有效备份 | 在「运行诊断」选择「恢复原主题图标」。MonoIcon 会关闭模块并恢复备份。 |
| 想恢复图标 | 在「主页」关闭「启用模块」，保持 Root 授权并等待恢复。若已更换系统主题，MonoIcon 会保留当前主题。 |

卸载前先在 MonoIcon 内完成恢复。直接卸载可能留下仍在生效的主题归档。若已卸载，可以通过 HyperOS 的「主题」重新应用图标主题。

反馈时附上机型、完整系统版本、桌面版本、MonoIcon 版本和复现步骤。可以在「模块设置」打开「发送日志」并保存日志。 [反馈问题](https://github.com/Jerrey-liang/MonoIcon/issues) [兼容性报告模板](compatibility-report.md)
