# MonoIcon

为 HyperOS 应用换上随壁纸配色的单色图标，无需安装图标包或主题。

[下载最新版](https://github.com/Jerrey-liang/MonoIcon/releases/latest) · [发布说明](docs/RELEASE_NOTE.md) · [反馈问题](https://github.com/Jerrey-liang/MonoIcon/issues) · [English](#english)

## 功能

- 用 Material 2025 或 Material 3 从桌面壁纸取色，各有九种配色风格，跟随系统明暗模式。
- 实时预览图标圆角和大小。桌面支持大图标。MonoIcon 生成的图标还可调整图案圆角与白边。
- 在「应用图标定制」中单独调整每个应用，选择应用自带的主题图标、内置 Lawnicons 或由 MonoIcon 生成。

## 使用前确认

需要 Android 15 或更高版本、Root 权限和支持 API 102 的 LSPosed。支持的 HyperOS 3 和 HyperOS 4 设备取决于具体系统和桌面版本。

官方 HyperOS 4 配置已在 Redmi K50（22041211AC）上验证，系统为 **HyperOS 4 OS4.0.0.3.XAACNXM（Android 17）**，桌面为 **RELEASE-8.01.02.6144-260818-08251107-R**。其他桌面版本、平板和折叠屏的验证仍有限。系统或桌面更新后请重新确认匹配情况。 [兼容范围](docs/HyperOS4%20profile%E7%BC%96%E5%86%99%E6%8C%87%E5%8D%97.md#compatibility)

## 安装与使用

1. 从发布页下载并安装 APK。
2. 在 LSPosed 中启用 MonoIcon，勾选「系统桌面」和「系统界面」两个作用域。
3. 打开 MonoIcon，授予 Root 权限，在主页打开「启用模块」。
4. 使用 HyperOS 4 时，在「配置管理」确认兼容配置。要导入配置文件，点「导入 Profile」。在 2.4.0 中，入口位于运行报告下方。 [配置指南](docs/HyperOS4%20profile%E7%BC%96%E5%86%99%E6%8C%87%E5%8D%97.md)
5. 在「图标样式」选择配色和形状，再点右上角电源菜单中的「重启作用域」应用设置。

从旧版升级至 2.4.0 时，先打开一次 MonoIcon，再重启手机。

## 已知限制与排查

- 日历和时钟使用静态图案。大图标更换形状后，可能需要重启桌面。关闭模块时，桌面会自动重启一次来恢复原图标。
- 文件夹、最近任务、通知入口和返回动画的验证范围有限。动态壁纸无法读取时会使用上次读取的壁纸或默认背景。
- 图标没有变化时，检查 LSPosed 作用域、Root 授权和「启用模块」。使用 HyperOS 4 时也请检查配置匹配情况。
- 桌面启动失败时，启动保护可能自动停用模块。要重试，在主页重新开启「启用模块」，再点「重启作用域」。

## English

MonoIcon gives HyperOS apps monochrome icons that match your wallpaper, with no separate icon pack or theme needed.

[Download](https://github.com/Jerrey-liang/MonoIcon/releases/latest) · [Release notes](docs/RELEASE_NOTE.md) · [Report an issue](https://github.com/Jerrey-liang/MonoIcon/issues)

### Features

- Choose Material 2025 or Material 3. Both offer nine wallpaper-based colour schemes and follow system light and dark modes.
- Preview icon corners and size as you adjust them. MonoIcon also supports large icons on the launcher. For icons generated by MonoIcon, you can also adjust artwork roundness and padding.
- Use **App icon customization** to adjust individual apps and choose app-provided themed icons, built-in Lawnicons, or icons generated by MonoIcon.

### Requirements

You need Android 15 or newer, root access and an LSPosed build that supports API 102. HyperOS 3 and HyperOS 4 compatibility depends on your system and launcher versions.

The official HyperOS 4 profile was verified on a Redmi K50 (22041211AC) running **HyperOS 4 OS4.0.0.3.XAACNXM (Android 17)** and launcher **RELEASE-8.01.02.6144-260818-08251107-R**. Validation of other launcher versions, tablets and foldables is limited. Check compatibility again after system or launcher updates. [Compatibility details (Chinese)](docs/HyperOS4%20profile%E7%BC%96%E5%86%99%E6%8C%87%E5%8D%97.md#compatibility)

### Installation and setup

1. Download and install the APK from the release page.
2. Enable MonoIcon in LSPosed and select both **System launcher** and **System UI**.
3. Open MonoIcon, grant root access and turn on **Enable module** on the home page.
4. On HyperOS 4, check for a matching profile under **Configurations**. To import a profile, select **Import Profile**. In 2.4.0, scroll below the runtime reports to find it. [Configuration guide (Chinese)](docs/HyperOS4%20profile%E7%BC%96%E5%86%99%E6%8C%87%E5%8D%97.md)
5. Choose your colours and shape under **Icon style**, then select **Restart scope** from the top-right power menu.

When upgrading to 2.4.0, open MonoIcon once, then reboot your phone.

### Known limits and troubleshooting

- Calendar and Clock use static artwork. Changing the shape of large icons may require a launcher restart. Turning off the module restarts the launcher once to restore the original icons.
- Testing of folders, recents, notification icons and return animations is limited. If MonoIcon cannot read a live wallpaper, it uses the last retrieved wallpaper or the default background.
- If icons stay unchanged, check the LSPosed scopes, root permission and **Enable module**. On HyperOS 4, also check that your profile matches.
- Startup protection may disable the module if the launcher fails to start. To retry, turn **Enable module** back on and select **Restart scope**.
